### 🚀 Featured QA Automation Projects

#### 🔹 [E-Commerce Playwright Automation Framework](https://github.com/YemiQA/ecommerce-playwright-automation)
An automation framework for automationexercise.com covering both UI and API testing, built to handle end-to-end user journeys across multiple browsers.
*   **Architecture:** Using **Playwright** with **TypeScript** on **Node.js**, using shared helper functions for reusable test steps.
*   **Key Implementations:** Integrated dynamic test data generation and cross-browser execution on Chromium, Firefox and WebKit.
*   **Reporting:** Documented a Chromium-only failure found during testing as a bug report with evidence screenshots.

#### 🔹 [SauceDemo UI E-Commerce Test Suite](https://github.com/YemiQA/saucedemo-playwright-tests)
An end-to-end UI automation framework designed to validate the user journeys, shopping cart workflows, and checkout processes of the Swag Labs website.
*   **Architecture:** Built using **JavaScript**, **Playwright Test**, and **Page Object Model (POM)** pattern.
*   **Key Implementations:** Created reusable page objects, added automated item sorting tests, saved login states to skip repeated logins, and used data-driven test files.
*   **Reporting:** Integrated Playwright HTML Reports and Trace Viewer to easily debug failed steps, screenshots, and network logs.

#### 🔹 [RESTful API Test Automation Engine](https://github.com)
A data-driven automation framework designed to comprehensively validate microservice endpoints under varying loads and payloads.
*   **Architecture:** Built using **Java**, **REST Assured**, and **TestNG**.
*   **Key Implementations:** Implemented custom JSON schema validation, automated bearer token authentication handling, and parameterized data provider injection.
*   **Reporting:** Integrated Allure Reports for rich visual breakdowns of assertion failures and payload histories.

#### 🔹 [Behavior-Driven Development (BDD) Framework](https://github.com)
A cross-browser automated testing repository bridging business requirements and technical verification.

### 🧠 Core Quality Engineering Practices

*   **Strategic Test Planning:** Crafting granular test strategies focusing on heavy automation for regression, supplemented by targeted exploratory testing for critical features.
*   **Defect Lifecycle Mastery:** Writing highly technical, reproducible bug reports paired with logs, network payloads, and stack traces to minimize developer back-and-forth.
*   **Flakiness Mitigation:** Architecting smart element-locators (prioritizing data-attributes) and avoiding hardcoded sleep statements to guarantee reliable test runs.
